# AI Town: Generative Agent Simulation

## Overview

Build a generative agent simulation from scratch, inspired by the "Generative Agents: Interactive Simulacra of Human Behavior" paper. The system simulates believable human behaviors through a cognitive loop: Perceive → Retrieve → Plan → Reflect → Execute.

**Goal**: Learn agent architecture (memory, reflection, retrieval) by building a clean implementation. Use SiliconFlow API for LLM calls.

**Scope**: 3 agents, Smallville-style tile map, real-time web visualization + replay capability.

**Status**: Core memory + cognitive loop complete (96 tests). Simulation engine and frontend in progress.

## Memory System

### 1. Spatial Memory (`memory/spatial.py`)

Tree structure representing the world map hierarchy:

```
the villa
├── reza house
│   ├── bedroom 1
│   │   └── [bed, closet, desk]
│   ├── kitchen
│   │   └── [stove, fridge, table]
│   └── common room
│       └── [sofa, TV, bookshelf]
├── garden
│   └── [bench, fountain, flowers]
└── grocery store
    └── [counter, shelves, cart]
```

- Used by agents to know WHERE things are
- Loaded from map data at startup
- Updated when agent discovers new areas

### 2. Associative Memory (`memory/associative.py`)

The "memory stream" — a chronological list of everything that happened.

Each memory node stores:
```python
{
    "node_id": "node_42",
    "type": "event|thought|chat",
    "created": datetime(2026, 5, 23, 8, 30),
    "expiration": datetime(2026, 6, 22, 8, 30),  # thoughts expire in 30 days
    "subject": "Isabella",
    "predicate": "is",
    "object": "painting",
    "description": "Isabella is painting in her studio",
    "embedding": [0.1, 0.2, ...],  # vector from SiliconFlow
    "poignancy": 7,  # importance score 1-10
    "keywords": {"isabella", "painting", "studio"},
    "filling": ["node_40", "node_41"]  # evidence nodes (for thoughts)
}
```

Three sequences:
- `seq_event`: things that happened (perceived actions)
- `seq_thought`: reflections and insights generated by the agent
- `seq_chat`: conversations between agents

**Retrieval scoring**:
```
score = recency_w * recency + relevance_w * relevance + importance_w * importance
```
- **Recency**: exponential decay based on time since creation (`0.99^i`)
- **Importance**: the poignancy score (1-10, assigned by LLM)
- **Relevance**: cosine similarity between memory embedding and current focus embedding

Weights: `recency_w=1, relevance_w=1, importance_w=1` with global weights `[0.5, 3, 2]`

### 3. Scratch Memory (`memory/scratch.py`)

Current state + identity. Not persisted long-term, but essential for the cognitive loop:
- Identity: name, age, traits, lifestyle
- Current action: what am I doing right now, where, for how long
- Planning: today's schedule, daily goals
- Reflection triggers: counters that determine when to reflect

## Cognitive Loop

Each agent runs this cycle every simulation step (10 seconds of game time):

### Step 1: Perceive (`cognitive/perceive.py`)
- Look at surrounding tiles within vision radius (4 tiles)
- Find events happening nearby (other agents' actions, object interactions)
- Filter out events already in memory (within retention window, 5 most recent)
- Output: list of new event nodes to add to memory

### Step 2: Retrieve (`cognitive/retrieve.py`)
- Take perceived events as "focal points"
- For each focal point, search associative memory for relevant events + thoughts
- Score by: recency × 0.5 + relevance × 2 + importance × 3
- Return top 30 most relevant memories per focal point

### Step 3: Plan (`cognitive/plan.py`)
Two levels of planning:

**Long-term (once per day):**
- Generate wake-up hour based on lifestyle
- Generate daily plan: "8am wake up, 9am breakfast, 10am-2pm painting..."
- Decompose into hourly schedule

**Short-term (each step):**
- Check if current action is finished
- If finished, look at hourly schedule for next action
- Decompose the hourly action into 5-15 minute sub-actions
- Generate specific location and object for the action
- Output: action address (where + what)

### Step 4: Execute (`cognitive/execute.py`)
- Take the planned action
- Determine the target tile on the map (resolve address → walkable tiles)
- Calculate path (BFS pathfinding on 140×100 collision grid)
- Move agent one tile along path per step
- Record completed actions as events in associative memory
- Output: next tile, emoji, action description

### Step 5: Reflect (`cognitive/reflect.py`)
Triggered when importance counter reaches threshold (150 points):
- Generate 3 "focal points" from recent memories
- Retrieve relevant memories for each focal point
- Generate insights: "I noticed X, which means Y" (up to 5 insights per focal point)
- Store insights as "thought" nodes in associative memory
- Reset importance counter

## LLM Integration

**API providers** (`config.py`):
- SiliconFlow (primary): chat + embedding
- DashScope (fallback): chat only, no embedding fallback (incompatible vector spaces)

**API client** (`llm/client.py`):

1. `generate(prompt) → str` — Send a prompt, get a text response
   - Used for: planning, reflection, action generation
   - Multi-provider fallback on 403 (insufficient quota)
   - System message for role-play consistency

2. `get_embedding(text) → list[float]` — Get embedding vector for text
   - Used for: memory storage and retrieval scoring
   - Model: Qwen3-Embedding-8B (1024 dims)
   - No fallback — different models produce incompatible vector spaces

**Prompt structure**:
- Prompts are f-strings defined inline within each cognitive module
- Uses agent identity (`get_str_iss()`) + context (memories, schedule, etc.)
- Responses are parsed line-by-line (key: value format)
- Retry logic: 3 attempts per provider, rotate on 403

**Prompts (4 total)**:
1. `plan.py: generate_daily_schedule()` — "Create a daily schedule for today"
2. `plan.py: determine_action()` — "Generate action details for this task"
3. `reflect.py: generate_focal_points()` — "What questions should I reflect on?"
4. `reflect.py: generate_insights_and_evidence()` — "What patterns can I draw?"

## Simulation Engine

**Simulation loop** (`sim/engine.py`):
```python
class Simulation:
    def __init__(self, agents, llm_client):
        self.agents = agents        # dict of name -> Persona
        self.llm_client = llm_client
        self.curr_time = datetime(2023, 2, 14, 8, 0, 0)
        self.step_size = timedelta(seconds=10)
        self.step_count = 0
        self.history = []           # replay data: one entry per step
        # Load maze data once
        self.collision_grid, self.arena_grid, self.arena_id_to_name = load_mazes()

    def step(self):
        # Build per-step state for replay
        state = {"time": self.curr_time.strftime("%H:%M:%S"), "states": []}
        for name, agent in self.agents.items():
            agent.scratch.curr_time = self.curr_time
            agent_state = agent.step(maze=self.arena_grid, personas=self.agents)
            state["states"].append(agent_state)
        self.history.append(state)
        self.curr_time += self.step_size
        self.step_count += 1
        return state

        for _ in range(steps):
```

**Agent step** (`agent/persona.py`):
```python
def step(self, maze=None, personas=None):
    perceive(self, maze, personas)
    plan(self, self.llm_client)
    reflect(self, self.llm_client)
    if self.scratch.act_check_finished():
        record_action_event(self, self.llm_client)
    execute_action(self, self.collision_grid, self.arena_grid, self.arena_id_to_name)
    return self._get_state()  # dict for frontend
```

**replay.json** — compact, array-indexed by step:
```json
{
  "meta": {"start_time": "...", "step_duration": 10, "agents": [...]},
  "steps": [
    {"time": "08:00:00", "states": [
      {"x": 72, "y": 20, "address": "...", "desc": "...", "emoji": "☕", "chat": null}
    ]}
  ]
}
```
- `states[i]` maps to `meta.agents[i]`
- Each state: `[x, y, address, description, emoji, chat]`
- `chat` is null most steps, only set during conversations

**diary.md** — grouped by agent, consecutive identical actions merged:
```markdown
## Isabella Rodriguez
### 08:00 — 10:30
- serving coffee to customers @ the Ville:Hobbs Cafe:counter
```
- Generated by script (not LLM) — grouping + formatting only
- Human-readable, no parsing needed
